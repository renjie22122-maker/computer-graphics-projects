# Computer Graphics Projects

Ray tracing and path tracing implementations developed for COMP0027 (2025–26), using the UCLCG browser renderer.

- `RayTracerSimple.uclcg`: plane/cylinder intersections, shadows, reflection/refraction, Fresnel effects and constructive solid geometry.
- `PathTracer.uclcg`: emission, light transport, bounce sampling, throughput, anti-aliasing and variance-reduction work. Feature availability follows the defines in the saved file; motion blur is not enabled by default.

## Open

Open the [UCLCG renderer](https://uclcg.github.io/uclcg/) and use **Load Setup** to open one of these `.uclcg` files. These are renderer setup files, not ordinary standalone JavaScript applications. They contain GLSL shader code embedded in the provided JavaScript scaffold.
